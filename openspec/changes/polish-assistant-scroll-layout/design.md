## Context
新会话按钮使用 X=3 的 RenderTransform，实际绘制超出布局边界。独立滚动条宽 12px，左间距 4px；聊天区底部空隙 2px，输入卡圆角 14px。

## Goals / Non-Goals
保持消息独立列和原有滚动同步，不变更助手业务，不调整已批准的异常文字颜色。

## Decisions
- 删除按钮溢出变换，而非扩大父级裁剪区域。
- 保留 12px 滚动热区，右移 6px；可见滑块 6px，圆角 3px，轨道透明。复用 TextTertiaryBrush，悬停/拖动提高不透明度。局部模板保留 PART_Track 及原生拖动与轨道点击。
- 消息视口底部 Margin=-7px；聊天区底部 Margin=0，输入卡 ZIndex=1。独立滚动条停在输入卡顶边，不深入输入卡。待批准时取消视口负间距，批准卡置于上层。消息内容末尾加入 14px 空白（7px 重叠补偿 + 7px 呼吸空间），避免普通状态行按像素取整后正文贴进输入卡。

## Risks / Trade-offs
透明桌面截图受合成背景影响，使用真实控件加模拟着色背景验证几何与交互；配色判断仍交用户评审。滚动到底需确认最后消息不会被永久遮挡。

## Migration Plan
正常重新发布到新的时间目录，保留旧发布包，回退仅撤销本次局部布局。
