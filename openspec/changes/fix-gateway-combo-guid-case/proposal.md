# 问题

网关页面 Combo 模块在历史配置库使用大小写混合的文本 Guid 时，Combo 开关、成员开关或成员排序保存会提示“Combo 模型不存在”或“路由不存在”。

# 根因

配置库将 Guid 存储为 SQLite `TEXT`。EF Core 的 Guid 转换器把请求参数格式化为小写，而历史行可能保留大写文本；SQLite 默认文本比较区分大小写，导致列表读取能够得到实体，但按 Guid 更新时查询不到同一行。

# 修复目标

- 初始化配置库时将所有 Guid 主键和关系列统一为规范小写文本。
- 保持现有数据库结构、接口和运行时路径不变。
- 为混合大小写的 Combo、Route 关系增加失败回归测试，并验证现有保存流程。
