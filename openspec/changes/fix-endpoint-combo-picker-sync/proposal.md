# 问题

网关页面右侧新增、删除、重命名或停用模型组合后，左侧 Endpoint 的模型组合选择下拉仍显示操作前的快照。删除组合时，下拉项还会直接消失，用户无法分辨原绑定项为何失效。

# 根因

`GatewayComboBindingOption` 将组合名称和启用状态保存为不可变值，而 `GatewayViewModel` 为避免本地保存事件销毁行内编辑，刻意忽略 `LocalSave` 的整页刷新。各组合 mutation 只更新右侧 `Combos`，没有局部同步 Endpoint 的 `ComboOptions`；新增组合甚至没有把服务返回值加入当前 `Combos`。

# 修复目标

- 新增组合后立即加入右侧列表，并追加到每个 Endpoint 的模型组合选择下拉。
- 重命名或启停组合后，所有 Endpoint 下拉项立即刷新名称和状态；停用文案改为多语言“停用”。
- 删除组合后保留下拉 tombstone 项并显示多语言“不存在”，且不允许再选择不存在的组合。
- 不恢复整页刷新，不修改服务端 API、数据库结构或网关运行时契约。
