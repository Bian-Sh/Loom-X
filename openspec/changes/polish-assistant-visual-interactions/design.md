## Context

当前助手使用 LiveMarkdown.Avalonia 1.12.2，其说明明确指出旧版 SkiaSharp 会让部分 emoji 退化为单色；项目当前传递依赖仍为 SkiaSharp 2.88.9。消息滚动条目前只占聊天区右侧列，没有固定端点按钮，也未延伸到应用内容边缘。异常气泡使用专属最低 85% 不透明度表面，与普通消息的透明主题更新逻辑不同。

## Goals / Non-Goals

**Goals:**
- 用最小依赖覆盖修复 Markdown 彩色图标在完整历史渲染路径中的单色问题。
- 保留现有消息视口与外置滚动值同步，只调整滚动轨视觉、端点交互和放置范围。
- 让异常气泡使用现有危险语义透明 token，不再维护独立最低不透明度规则。

**Non-Goals:**
- 不改会话存储格式、Markdown 内容或助手请求协议。
- 不重做整个主窗口布局，不改变历史时钟按钮的位置。

## Decisions

- 在桌面项目显式固定兼容的 SkiaSharp 3.x 与 Windows 原生资产版本，覆盖 Avalonia 的旧传递版本；不对历史正文做字符替换，避免污染用户内容。
- 新增一个覆盖标题下边沿至应用底部的独立滚动轨容器；顶部/底部使用固定三角按钮，中间继续使用原生 Track 与 Thumb，代码后置只负责小步滚动和现有数值同步。相比把三角形塞进 Track 的页面按钮，这能保证端点位置固定。
- 滚动轨通过抵消主内容区右侧和底部 Padding 贴近窗口边缘；消息正文仍保留原宽度，不被滚动轨挤压。
- 异常气泡背景切换为现有 `DangerSoftBrush`，直接复用 `WindowAppearanceCoordinator` 已有的透明度更新路径；保持当前圆角、描边和正文色。
- 新会话按钮仅对自身施加 X=10 的视觉平移，历史按钮及标题居中计算保持不变。

## Risks / Trade-offs

- [SkiaSharp 主版本覆盖可能与 Avalonia 原生资产不匹配] → 同时固定托管包与 Win32 原生资产，运行完整测试、Release 构建和发布包启动验证。
- [负边距贴边可能受宿主裁剪影响] → 在真实 MainWindow 中生成控件预览并验证端点实际坐标。
- [端点按钮与 Track 同步偏差] → 端点直接修改外置 ScrollBar 的 Value，并复用已有 ValueChanged 同步消息视口。

## Migration Plan

重新发布到新的时间命名目录并保留旧包；若依赖或视觉验证失败，回退本次项目包引用和助手视图局部改动。
