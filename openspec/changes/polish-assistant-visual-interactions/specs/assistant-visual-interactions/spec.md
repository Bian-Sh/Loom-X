## Purpose

确保 AI 助手在实时输出、历史恢复和透明主题下维持一致、清晰且可操作的消息视觉与边缘交互。

## ADDED Requirements

### Requirement: Markdown 彩色图标在历史恢复后保持颜色

系统 MUST 让 Markdown 正文中的彩色 Unicode 图标在首次流式渲染与重新载入历史会话后保持一致的彩色呈现，不得退化为单色黑色字形。

#### Scenario: 重新打开含彩色图标的历史会话
- **WHEN** 助手正文包含红色圆点、绿色圆点、黄色警告或绿色对勾等彩色 Unicode 图标，并在稍后从历史列表重新打开
- **THEN** 图标颜色与首次渲染时一致，正文其余 Markdown 样式不受影响

### Requirement: 消息滚动条使用贴边端点与胶囊滑块

系统 MUST 在应用右侧边缘展示消息滚动条：顶部三角位于标题区下边沿，底部三角位于应用右下角，中间胶囊滑块支持拖动，划入时按当前主题加深。

#### Scenario: 消息超过可视区域
- **WHEN** 助手消息高度超过消息视口
- **THEN** 右侧贴边滚动轨显示上下三角与胶囊滑块，拖动、轨道点击和端点点击均能滚动消息

#### Scenario: 指针划入滑块
- **WHEN** 指针划入胶囊滑块
- **THEN** 滑块使用当前应用配色加深，离开后恢复默认弱化色

### Requirement: 异常气泡复用透明消息材质

系统 MUST 让异常气泡复用普通消息气泡的透明度与主题更新逻辑，同时保留红色语义表面、描边和当前正文配色。

#### Scenario: 调整透明主题参数
- **WHEN** 用户调整应用透明度或磨砂参数
- **THEN** 异常气泡与普通消息气泡同步改变透明程度，但仍可通过红色语义色与正常消息区分

### Requirement: 标题区新会话图标独立右移

系统 MUST 保持历史时钟图标位置不变，并将其右侧的新会话图标额外向右移动 10px。

#### Scenario: 查看助手标题区
- **WHEN** 助手页面显示历史时钟和新会话按钮
- **THEN** 历史时钟保持原位置，新会话图标相对当前布局向右偏移 10px
