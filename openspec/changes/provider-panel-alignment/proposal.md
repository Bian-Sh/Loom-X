# Provider 面板对齐与卡片操作

## 动机

当前 Provider 页面最外层滚动容器包住摘要和工作区，导致目录与详情无法稳定瓜分可用高度，窗口缩放时底部对齐不明确。目录卡片的启用开关还显示 `On` 文案，删除入口位于详情标题，空目录时右侧缺少明确状态。

## 目标

- 将摘要、Provider 目录、Provider 详情组织为固定顶部加自适应工作区。
- 保持目录和详情底部对齐，并保留主内容区 18px 底部 gap。
- 为目录卡片提供无重复文案的启用开关、删除图标和二次确认。
- Provider 为空时在右侧显示小型空状态提示。
- 移除基础 Tab 中重复的 Provider 启用复选框。

## 范围

仅修改 Avalonia Provider 页面及其展示状态，不修改配置格式、数据库、HTTP API 或已有保存/连接逻辑。
