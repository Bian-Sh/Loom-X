## ADDED Requirements

### Requirement: 基础 Tab 使用紧凑的接口兼容类型选择器
Provider 基础 Tab MUST 使用单个下拉菜单选择接口兼容类型；下拉选项 MUST 只显示兼容类型名称，当前类型对应的接口 URI MUST 在下拉菜单外以单行辅助信息展示。

#### Scenario: 切换接口兼容类型
- **WHEN** 用户在基础 Tab 打开接口兼容类型下拉菜单并选择另一类型
- **THEN** 下拉菜单显示新的兼容类型名称，下方辅助信息显示该类型对应的接口 URI，并继续使用现有配置字段保存选择

#### Scenario: 浏览兼容类型选项
- **WHEN** 用户展开接口兼容类型下拉菜单
- **THEN** 每个选项只显示类型名称，不在选项内部重复显示接口 URI
