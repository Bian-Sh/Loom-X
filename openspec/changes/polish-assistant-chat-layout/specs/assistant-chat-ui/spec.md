## Purpose

规范 AI 助手聊天页中标题操作区、消息滚动、消息输入与模型选择弹层的可见布局和交互，使界面在不同窗口高度下保持清晰、紧凑且不遮挡消息内容。

## ADDED Requirements

### Requirement: 标题操作与消息滚动条对齐

桌面端 MUST 使新会话按钮的图标中心与消息区纵向滚动条中心处于同一垂直轴线，并保持历史会话按钮与新会话按钮之间存在清晰间距。

#### Scenario: 默认窗口尺寸下显示标题操作区

- **WHEN** 用户以默认窗口尺寸打开 AI 助手页
- **THEN** 新会话图标中心与消息区纵向滚动条中心对齐，且不会紧贴历史会话图标

### Requirement: 消息滚动条避让对话内容

消息区纵向滚动条 MUST 位于消息内容区域之外的独立右侧列，并在内容可滚动时保持可见，不得覆盖或挤压用户对话气泡。

#### Scenario: 消息内容超过可视高度

- **WHEN** 消息内容高度超过消息区可视高度
- **THEN** 独立纵向滚动条在消息内容右侧显示，拖动时同步消息区偏移且不覆盖消息内容

### Requirement: 输入框按内容自动增高

消息输入框 MUST 支持多行自动换行并随内容增高，最大高度为应用客户区高度的 32%；达到最大高度后 MUST 在输入框内部提供纵向滚动，并保持 Enter 发送、Shift+Enter 与 Ctrl+Enter 换行。

#### Scenario: 输入少量多行内容

- **WHEN** 用户输入的内容高度低于应用客户区高度的 32%
- **THEN** 输入框随内容自然增高且不显示不必要的内部滚动条

#### Scenario: 输入内容超过高度上限

- **WHEN** 用户输入的内容高度超过应用客户区高度的 32%
- **THEN** 输入框停止增高并显示内部纵向滚动条以查看其余内容

#### Scenario: 使用键盘换行和发送

- **WHEN** 用户按 Shift+Enter 或 Ctrl+Enter
- **THEN** 输入框插入换行且不发送消息
- **WHEN** 用户单独按 Enter
- **THEN** 当前消息被发送

### Requirement: 状态消息与输入区保持稳定布局

状态消息 MUST 使用统一左对齐基线，不得因文本宽度不同而横向漂移；消息滚动区底边与复合输入框上边沿在没有批准卡片时 MUST 保持 2px 间距。

#### Scenario: 连续显示不同长度的失败状态

- **WHEN** 消息流连续出现长度不同的单行或多行失败状态
- **THEN** 所有状态从同一左侧基线开始，不按自身宽度居中

#### Scenario: 批准卡片未显示

- **WHEN** 当前没有待批准操作
- **THEN** 消息滚动区底边与复合输入框上边沿之间保持 2px 间距

### Requirement: 模型选择弹层保持紧凑比例

模型选择弹层 MUST 使用 256px 宽度和 360px 最大高度，并使用紧凑的搜索框、Provider 标题行与模型行，同时保持搜索、模型列表与思考等级控件完整可用。搜索框 MUST 透出弹层材质，模型名称越界时 MUST 使用省略号，并在悬停模型行时通过气泡展示完整名称。

#### Scenario: 打开模型选择弹层

- **WHEN** 用户点击输入区的模型选择按钮
- **THEN** 弹层以 256px 宽度打开，内容超过 360px 时模型列表可滚动且底部思考等级控件仍可见

#### Scenario: 透明主题下使用模型搜索框

- **WHEN** 用户启用透明主题并打开模型选择弹层
- **THEN** 搜索框普通、悬停和聚焦状态均透出弹层背景，同时保留边框和输入可读性

#### Scenario: 模型名称超过可用宽度

- **WHEN** 模型名称长于模型行的可用宽度
- **THEN** 行内名称以省略号结尾，用户悬停该行时气泡展示完整模型名称
