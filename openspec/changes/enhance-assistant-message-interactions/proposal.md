## Why

助手聊天中的用户消息与异常消息目前无法直接划词选择，且长对话只能依赖滚轮或滚动条浏览，交互能力与常规网页阅读体验不一致。需要补齐文字选择和中键自动滚动，让用户能够更自然地复制局部内容并快速浏览长对话。

## What Changes

- 用户消息气泡和终态异常气泡支持鼠标划词选择。
- 聊天消息区支持网页式中键自动滚动：中键进入、显示锚点、按鼠标与锚点的垂直距离连续平滑滚动。
- 自动滚动提供中性、向上和向下的可见状态，并可通过再次点击、其他鼠标键、Esc、失去指针捕获或卸载页面退出。
- 自动滚动继续复用现有消息视口、外置滚动条和“跳至最新消息”状态同步。

## Capabilities

### New Capabilities

- `assistant-message-interaction`: 规定助手消息文字选择和聊天区中键自动滚动的用户可见行为。

### Modified Capabilities

无。

## Impact

- 影响 `AssistantView` 的消息模板和输入事件处理。
- 增加对应的 Avalonia 视图契约与滚动计算测试。
- 不修改数据模型、会话存储、公共 API 或数据库结构。
