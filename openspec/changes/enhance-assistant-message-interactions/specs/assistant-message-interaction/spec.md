## Purpose

定义助手聊天消息区的文字选择与网页式中键自动滚动行为，使用户能够选择局部消息文本，并在长对话中连续、可控地浏览内容。

## ADDED Requirements

### Requirement: 用户可以选择消息气泡正文
系统 SHALL 允许用户在用户消息气泡和终态异常气泡中使用指针划词选择正文，同时保持气泡现有的换行、排版和视觉样式。

#### Scenario: 选择用户消息中的局部文字
- **WHEN** 用户在用户消息正文上按住主键并拖动
- **THEN** 被拖过的文字进入可选择状态

#### Scenario: 选择异常消息中的局部文字
- **WHEN** 用户在终态异常消息正文上按住主键并拖动
- **THEN** 被拖过的文字进入可选择状态

### Requirement: 聊天区支持中键自动滚动
系统 SHALL 在聊天消息视口存在垂直可滚动内容时，允许用户通过中键进入网页式自动滚动模式，并根据指针相对启动锚点的垂直位移连续更新消息视口。

#### Scenario: 进入自动滚动模式
- **WHEN** 聊天消息区可垂直滚动且用户按下鼠标中键
- **THEN** 系统在按下位置显示自动滚动锚点并切换为垂直滚动光标

#### Scenario: 指针位于锚点死区内
- **WHEN** 自动滚动模式已启动且指针位于锚点附近的垂直死区
- **THEN** 消息视口保持当前位置

#### Scenario: 指针离开锚点死区
- **WHEN** 自动滚动模式已启动且指针移动到锚点上方或下方
- **THEN** 消息视口分别向上或向下平滑滚动，并且距离越远滚动速度越快

#### Scenario: 自动滚动到达边界
- **WHEN** 自动滚动尝试超过消息视口顶部或底部
- **THEN** 视口停留在对应边界且不会产生越界偏移

#### Scenario: 退出自动滚动模式
- **WHEN** 用户再次按下中键、按下其他鼠标键、按下 Esc、指针捕获丢失或聊天视图卸载
- **THEN** 系统停止自动滚动、隐藏锚点并恢复原有光标

#### Scenario: 消息区不可滚动
- **WHEN** 消息内容未超过视口且用户按下鼠标中键
- **THEN** 系统不进入自动滚动模式

### Requirement: 混合文字保持一致基线
系统 SHALL 在助手页优先使用普通文本字体渲染英文和阿拉伯数字，并使用兼容的中文字体与彩色 Emoji 回退，使未选择与已选择状态下的混合文字保持稳定的垂直基线。

#### Scenario: 英文数字与中文混排
- **WHEN** 聊天正文同时包含中文、英文单词和阿拉伯数字
- **THEN** 英文和数字不应明显高于相邻汉字，划词选择前后也不应产生下沉错觉

#### Scenario: 正文包含 Emoji
- **WHEN** 助手 Markdown 正文包含彩色 Emoji
- **THEN** Emoji 保持彩色渲染且普通英文、数字不由 Emoji 字体接管
