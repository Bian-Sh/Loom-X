## Context

当前用户消息和终态异常消息使用普通 `TextBlock`，助手 Markdown 正文已具备选择能力。消息区由 `MessageScroll` 管理视口，并通过代码后置同步外置滚动条和“跟随最新消息”状态。

## Goals / Non-Goals

**Goals:**

- 使用 Avalonia 原生可选择文本控件补齐用户与异常气泡的局部文字选择。
- 在不替换现有 `ScrollViewer` 和外置滚动条的前提下增加网页式中键自动滚动。
- 让滚动速度与指针垂直距离连续关联，并设置中心死区和最大速度。
- 确保退出路径完整，不遗留指针捕获、计时器或光标状态。
- 将 Markdown 普通文字与 Emoji 拆分为独立字体运行段，避免页面切换后的字体回退缓存同时破坏彩色 Emoji 与混合文字基线。

**Non-Goals:**

- 不改变消息模型、复制按钮或会话持久化。
- 不替换 LiveMarkdown 渲染器，只扩展其普通文字节点的字体运行段生成。
- 不增加水平自动滚动。
- 不引入新的第三方依赖或平台专用原生钩子。

## Decisions

### 使用 `SelectableTextBlock` 替换两类普通正文控件

`SelectableTextBlock` 能保留现有文字布局属性，并直接提供 Avalonia 原生选择行为。相比为 `TextBlock` 自行实现选择或改用可编辑 `TextBox`，它不会引入编辑状态、焦点边框和额外文本同步。

### 自动滚动由 `AssistantView` 代码后置管理

该行为只依赖具体视图的指针位置、视口偏移和可见锚点，放入现有代码后置可以直接复用外置滚动条同步与跟随状态。相比新增通用 Behavior，本次单一视图需求不值得引入额外抽象。

### 使用指针捕获和约 60 FPS 的 `DispatcherTimer`

进入模式后捕获指针，使移动和退出事件稳定回到消息视口。计时器根据真实经过时间计算位移，避免不同刷新频率导致速度变化。速度函数采用中心死区、线性增速和上限，兼顾微调和长距离浏览。

### 使用视图内矢量锚点和 Avalonia 标准垂直滚动光标

锚点直接在消息区覆盖层绘制，不新增图片资产。进入模式时使用标准 `SizeNorthSouth` 光标，锚点内上下箭头根据滚动方向改变强调状态，从而提供中性、向上和向下反馈。


### 助手 Markdown 使用独立的文字与 Emoji 运行段

仅调整同一字体回退链的顺序无法同时满足两个目标：Emoji 字体在首位会接管英文和数字并造成基线上浮，普通文本字体在首位又会在页面往返后被 Skia 字体回退缓存解析为单色 Emoji。应用在 LiveMarkdown 节点管线中替换普通文本节点，把 Unicode 文本元素按 Emoji 与普通文字合并成独立 `Run`。普通运行段显式使用 `Segoe UI, Microsoft YaHei UI`，Emoji 运行段显式优先使用 `Segoe UI Emoji`；Markdown 容器自身只保留普通文本字体链。这样字体选择不再依赖易受页面切换影响的隐式回退缓存，同时保留 LiveMarkdown 的流式更新、样式继承和文字选择。

## Risks / Trade-offs

- [标准光标与浏览器专用自动滚动光标外形不完全一致] → 通过固定锚点和方向高亮明确表达当前模式，并避免新增平台专用光标资产。
- [指针事件与文字选择冲突] → 仅消费中键和自动滚动退出点击，普通左键拖动仍由 `SelectableTextBlock` 处理。
- [流式消息增长期间自动滚动影响跟随状态] → 所有位移仍通过现有 `MessageScroll.Offset`，沿用既有 `ScrollChanged` 状态判定。
- [自定义 Markdown 普通文本节点影响格式继承] → 仅替换 `LiteralInline` 的叶子节点，继续复用原有 Span、链接、强调、选择范围与流式增量更新，并为生成的 Run 保留 `Literal` class。
