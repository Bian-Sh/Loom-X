# 概览最近请求显示修复

## 问题

概览页右下角“最近请求”只接收当前桌面进程内的实时遥测完成事件。已有请求活动已经写入 `Activity.db` 时，概览初始化不会加载这些记录，因此重启桌面或首次进入概览时列表为空或数据不完整。列表模板虽然定义了多列，但行内 `TextBlock` 未设置 `Grid.Column`，所有字段叠在默认第 0 列，造成数据看起来异常；同时状态字段没有展示。

## 根因

`OverviewViewModel` 没有复用活动数据库查询服务进行初始化回填，只在 `ApplyTelemetry` 中维护内存集合；`OverviewView.axaml` 的列表列定义遗漏了各子项的 `Grid.Column` 和 `Status` 显示。

## 修复目标

- 概览初始化和刷新时从统一的 `Activity.db` 查询最近 8 条请求，并按创建时间倒序显示。
- 实时完成事件继续插入列表，同时避免与数据库回填产生重复项。
- 列表展示时间、Endpoint、Model、状态和延迟，空数据时保持稳定。
- 增加回归测试覆盖数据库排序/映射与实时列表更新行为。
