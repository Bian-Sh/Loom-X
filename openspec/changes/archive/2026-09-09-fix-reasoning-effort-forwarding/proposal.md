# 推理强度转发修复

## 问题

OllamaHub 的 Ollama 兼容入口在选择 OpenAI Responses/Chat Completions 上游时，只替换了请求模型名，没有合并模型配置中的额外请求字段。因此配置在模型 `Extra` 中的 `reasoning_effort` 不会出现在发往中转站的请求体中。

## 修复目标

- Ollama 兼容入口按每条路由尝试构造独立请求，并合并该模型的额外请求字段。
- 保留请求原有字段和协议桥接行为；模型配置字段沿用 OpenAI 兼容入口的现有覆盖规则。
- 增加回归测试，验证 `reasoning_effort` 被转发且多路由尝试之间不会互相污染。

## 范围

不新增公开 API、配置表字段或协议能力，只修复已有模型额外字段未进入上游请求的问题。
