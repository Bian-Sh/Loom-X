# 修复设计

Provider 编辑器记录 API Key 是否被用户编辑。配置响应从 DPAPI 密文解密出当前密钥，加载时回填编辑框并重置编辑标志；用户对 TextBox 做出实际修改（包括清空）时设置编辑标志。生成 `ProviderInput` 时，未编辑传 `null` 表示不修改，已编辑则传入当前字符串，空字符串仍表示显式清除。配置服务已有对应语义，因此更新 Enabled、UseProxy 或其它字段时不会覆盖已有密钥。

API Key 默认以掩码显示，眼睛图标在输入框右侧切换明文和掩码；显示状态只影响当前控件，不改变保存值或编辑标志。数据库仍只保存 DPAPI 密文。

回归测试覆盖未编辑时生成 `null`、用户清空时生成空字符串，以及加载带密钥响应后仍保持未编辑状态。
