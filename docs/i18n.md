# Loom-X i18n (国际化) 工作流

## 架构

- **Strings.resx**：唯一源文件（`LoomX/Resources/Strings.resx`），默认语言 `zh-CN`
- **LocaleService**：全局文化状态管理，`CultureChanged` 事件驱动 UI 刷新
- **`{l:Locale "key"}`**：AXAML 标记扩展，返回响应式绑定
- **`IStringLocalizer<T>`**：ViewModel 中使用，通过 `LocalizerFactory.Create<T>()` 获取

## 添加新字符串

1. 在 `LoomX/Resources/Strings.resx` 添加 `<data name="key"><value>值</value></data>`
2. AXAML 中：`Text="{l:Locale key}"`
3. C# 中：`_loc["key"]` 或 `Loc("key")`

## 添加新语言

1. 创建 `LoomX/Resources/Strings.{culture}.resx`（如 `Strings.en-US.resx`）
2. 复制所有 `<data>` 条目，修改 `<value>` 为翻译
3. 构建后自动生成卫星程序集

## 键命名规范

- `nav.*`：主导航
- `settings.*`：设置页
- `window.*`：窗口控件
- `sidebar.*`：侧边栏
- `update.*`：更新提示
- `app.*`：应用级
- `providers.*`：Provider 与模型管理
- `gateway.*`：Endpoint、Combo 与故障转移
- `placeholder.*`：占位页面

## 工作流（XLIFF）

**Phase 3 计划接入。** 如果后续需要翻译协作，可以引入 [XliffTasks](https://github.com/microsoft/Globalization)：

```xml
<!-- csproj -->
<PackageReference Include="XliffTasks" Version="2.*" PrivateAssets="all" />
<PropertyGroup>
  <XliffTasksDefaultLanguage>zh-CN</XliffTasksDefaultLanguage>
  <XliffTasksOutputPath>.xlf</XliffTasksOutputPath>
</PropertyGroup>
```

```bash
dotnet xliff generate   # 从 .resx 生成 .xlf
dotnet xliff compile    # 从 .xlf 编译回 .resx
```

## 插件文案归属

宿主 resx 只放宿主自己的文案。**插件文案一律放插件目录下的 `i18n/<culture>.json`**，宿主资源里不得出现任何插件专属键。

| 插件 | 文案目录 | 解析入口 |
|------|---------|---------|
| Credential Protection | `plugins/LoomX.CredentialProtection/i18n/*.json` | `CredentialSettingsText.Resolve` |
| Tool Result Compression | `plugins/LoomX.ToolResultCompression/i18n/*.json` | `CompressionSettingsText.Resolve` / `ToolResultCompressionUiText.Resolve` |

- 解析统一走 `LoomX.Plugin.Abstractions` 的 `PluginTextCatalog.For(owner, pluginId, cultureName)`。`pluginId` 必须传插件自己的 `PluginId` 常量。
- 查找顺序：程序集所在目录的 `i18n/<culture>.json`（正式运行时即 `plugins/<id>/i18n/`）→ 宿主目录的 `plugins/<id>/i18n/<culture>.json`（程序集被摊平时，例如测试工程）→ 嵌入程序集的 `en-US`。**没有按程序集名分层的特判**，理由见 `AGENTS.md` 的「插件负载布局与命名」。
- 文件名固定 `<culture>.json`，与运行时布局完全一致；冲突靠目录隔离，不靠改名。
- 每个插件的 `en-US.json` 同时声明为 `EmbeddedResource`，保证只拷一个 DLL 时也不会显示原始键名。
- 新增语言时，只需在每个插件的 `i18n/` 下补一个同名文件并提交 JSON，无需改动宿主或重新编译插件。

### Phase 2 扫描边界

本阶段的 CJK 扫描覆盖所有 `Views/*.axaml` 和 Phase 2 目标 ViewModel（`GatewayViewModel`、`MainWindowViewModel`），并排除资源文件、日志模板和注释。扫描清单中发现的非目标残留暂留后续阶段：`UpdateCoordinator`、`SettingsViewModel`、`ActivityViewModel`、Providers 删除确认对话框和 Activity 复制 Toast；它们分别归入后续的 `update.*`、`settings.*`、`activity.*` 迁移，不影响本阶段已支持页面。
