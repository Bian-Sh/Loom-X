# 移除无效控制中心启动设置设计

## 目标

移除左侧导航中的“运维”分割标签，并彻底删除“启动时打开控制中心”设置。应用启动行为保持现状：桌面端启动后直接显示主窗口，不增加托盘或后台启动逻辑。

## 方案

- 导航项不再携带分组标签，删除 `NavigationItemViewModel` 的分组属性及对应 XAML 展示绑定。
- 从设置页、`SettingsViewModel`、设置 API 输入/输出契约、数据库实体和配置快照中删除 `OpenControlCenterOnStartup`。
- 设置保存参数顺序同步调整，保留其他设置字段和自动保存行为不变。
- 数据库初始化创建表时不再创建该列；对已有数据库执行一次 SQLite 列删除，保证旧数据 schema 不继续保留无效字段。
- 启动入口不做额外修改，继续由 Avalonia 桌面生命周期创建并显示 `MainWindow`。

## 验证

- 全仓搜索不再出现该设置名或“运维”分割标签。
- 构建桌面端和测试项目。
- 运行现有自动化测试，重点覆盖设置服务契约和数据库初始化兼容性。
