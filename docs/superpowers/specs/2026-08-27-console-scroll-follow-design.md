# 控制台滚动跟随设计

## 目标

控制台采用接近 Unity Console 的滚动跟随逻辑，删除显式的暂停和自动滚动控制，让界面更简洁。

## 交互

- 删除“暂停日志 / 继续日志”按钮。
- 删除“自动滚动”复选框。
- 日志视口默认跟随底部。
- 用户滚动到距底部超过 `32px` 时停止自动跟随。
- 用户滚回距底部 `32px` 内时自动恢复跟随。
- 停止跟随时，在日志视口底部居中显示向下箭头按钮。
- 点击向下箭头后滚动到底部并恢复自动跟随。
- 清空当前视图仍保留，不删除日志文件。

## 布局

- 控制台面板占满页面标题下方的剩余可用高度。
- 工具栏位于面板顶部。
- 日志 ScrollView 填满工具栏与底部状态栏之间的空间。
- 底部状态栏固定在面板底部，不再作为控制台外部的附加区域。

## 实现约束

- 继续使用自包含 HTML、CSS 和 JavaScript，不新增依赖。
- 通过 `scrollTop + clientHeight` 与 `scrollHeight` 判断是否接近底部。
- 筛选或重新渲染日志时，仅在跟随状态下滚到底部。
- 完成后运行 `.design/scripts/validate.ps1`，并检查旧控件和关联脚本是否完全移除。
