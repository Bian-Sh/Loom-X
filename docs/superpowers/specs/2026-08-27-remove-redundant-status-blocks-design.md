# 移除重复状态信息块设计

## 目标

减少页面中与标题或主体内容重复的状态信息，保持界面层级简洁。

## 调整范围

- 网关页删除“3 个 Endpoint、4 条启用路由、更改实时保存”摘要条。
- Provider 页删除 SQLite 配置条幅。
- Provider 页侧栏底部改为统一的软件版本信息：`服务版本 / v0.12.6 · 正在运行`。

## 非目标

- 不改网关 Endpoint 卡片、模型路由和实时保存交互。
- 不改 Provider 统计卡片、Provider 列表、自动保存和导航。
- 不修改其他四页已经统一的版本栏。

## 验证标准

- 网关页不存在 `.summary[data-ds-section="网关摘要"]`。
- Provider 页不存在 `.sqlite-strip`。
- 五页侧栏底部均显示“服务版本”和当前版本号。
- 原型校验脚本通过，页面标题、链接和当前导航保持有效。
