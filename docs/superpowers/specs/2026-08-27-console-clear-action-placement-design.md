# 控制台清空操作位置设计

## 目标

将控制台的清空操作从顶栏移到底部日志状态栏，减少标题区操作干扰，并让清空动作与日志统计信息保持在同一上下文中。

## 交互规则

- 顶栏不再显示“清空当前视图”。
- 底部状态栏左侧继续显示日志数量。
- 底部状态栏右侧显示日志文件说明，并追加“清空”按钮。
- 点击“清空”继续清空当前视图，不删除日志文件，并显示现有 toast 提示。
- 移动端底栏允许换行，清空按钮保持可见且位于说明文字之后。

## 验证标准

- 顶栏不存在 `clearBtn`。
- 底栏包含 `clearBtn`，按钮文案为“清空”。
- 清空按钮仍绑定原有清空逻辑。
- JavaScript 语法和 `.design/scripts/validate.ps1` 均通过。
