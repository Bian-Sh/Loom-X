# 页面标题上移设计

## 目标

消除五个原型页面顶栏中的重复页面名称，并将页面主标题、板块注释及其同级操作区上移到顶栏。保留顶栏底部分割线，让标题区与主体内容仍有清晰边界。

## 适用范围

统一调整 `.design/pages` 下的五个主页面：

- `overview`
- `gateway`
- `providers`
- `activity`
- `console`

## 布局规则

- 删除顶栏内的 `OllamaHub / 当前页面` 面包屑文字。
- 将原页面标题区整体移入 `.topbar`，包括 `h1`、板块注释以及同级操作按钮。
- 顶栏继续使用 `border-bottom` 作为分割线。
- 主内容区删除已迁移的标题区，并缩减对应顶部留白。
- 移动端保留菜单按钮；菜单按钮与标题文案组成同一标题行，操作区在空间不足时换行或下沉。
- 不改变页面标题、注释文案、按钮行为及主体业务交互。

## 页面差异

- 概览页原 `.heading` 迁入顶栏；该页没有标题区操作按钮。
- 网关页原 `.page-head` 迁入顶栏；该页没有标题区操作按钮。
- Provider 页的“新增 Provider”随标题区一起迁入顶栏。
- 活动页原 `.page-head` 迁入顶栏；该页没有标题区操作按钮。
- 控制台页的“清空当前视图”随标题区一起迁入顶栏。

## 验证标准

- 五页顶栏均不再显示重复面包屑文字。
- 五页标题和注释均位于分割线上方。
- Provider 与控制台的标题区操作按钮仍可使用。
- 桌面和移动断点下无明显溢出、遮挡或多余空白。
- `.design/scripts/validate.ps1` 校验通过。
