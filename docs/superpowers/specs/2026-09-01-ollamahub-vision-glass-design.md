# OllamaHub Vision Glass 视觉改造设计

## 目标

将 Avalonia 桌面端六个业务页面统一为 Vision Pro / Fluent 风格的浅色磨砂玻璃界面：背景使用柔和的暖灰白，导航、标题栏和浮层使用半透明材质，表格、表单和日志使用稳定的不透明表面。改造只影响视觉层和控件呈现，不改变现有命令、绑定、数据流和页面职责。

## 设计令牌

- 背景：`#F3F5F6`，辅以极低对比度的冷暖层次。
- 材质：`Glass` 使用约 80% 不透明白色，`GlassStrong` 使用约 92% 不透明白色；两者配合细边框表达层级。
- 文字：主文字 `#172126`，次文字 `#5F6D73`，三级文字 `#8A969B`。
- 强调色：低饱和青灰 `#287C83`，成功 `#2D8666`，警告 `#9A6B2B`，错误 `#A94E59`。
- 间距：只使用 4/8/12/16/20/24/32；控件高度统一为 34/36/40。
- 圆角：4/8/12，避免大面积胶囊形。

## 组件边界

`App.axaml` 提供全局颜色、字体、按钮、输入框、列表项、Tab 和 ToggleSwitch 样式。`MainWindow.axaml` 负责玻璃导航、标题栏、品牌标记和 Toast。页面 XAML 只保留布局语义与必要的页面专属状态色，不再定义互相冲突的基础控件外观。

## 页面落点

- 概览：浅色工作区 + 深色拓扑画布作为唯一高对比焦点，指标和网关卡片采用标准表面。
- 网关：Endpoint 目录与 Combo 编辑器使用两列稳定布局，选中项使用青灰玻璃高亮。
- Provider：目录与编辑器采用相同的面板、输入框和 Tab 令牌，模型表格保持密度。
- 活动：统计卡片、筛选工具栏、请求列表和详情面板共享边框与状态色。
- 控制台：日志视口保持不透明、等宽字体和行分隔；工具栏使用轻玻璃层。
- 设置：Tab、表单分组和操作按钮使用统一控件高度与间距。

## 可访问性与行为

保留现有 AutomationProperties、命令绑定、事件处理和键盘焦点；焦点环使用强调色，文本对比度不低于现有主题。禁止继续使用 Unicode 字符作为图标，新增图标使用 `PathIcon` 几何路径。

## 验证

运行 `dotnet build OllamaHub.slnx`，启动 `OllamaHub.Desktop`，依次检查概览、网关、Provider、活动、控制台、设置，确认窗口缩放到最小尺寸时无明显重叠或裁切。
