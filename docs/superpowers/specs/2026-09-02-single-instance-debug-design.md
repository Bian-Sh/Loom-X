# 桌面端并行调试启动设计

## 目标

允许本次调试发布包与已运行的 OllamaHub 实例并行启动，以便验证透明外观设置。正常启动仍保持单实例约束。

## 方案

在桌面端启动逻辑中增加环境变量 `OLLAMAHUB_ALLOW_MULTIPLE_INSTANCES=1` 作为显式调试开关。开关未设置或取值不是 `1` 时，继续创建并检查现有 Shell 引导锁和桌面单实例锁；开关启用时跳过两处互斥锁。该变量不写入设置数据库、不出现在 UI，也不改变发布包默认行为。

## 验证

通过带环境变量的独立发布包确认新窗口可以启动，并使用透明度、磨砂程度和算法控件验证 `ApplyAppearance` 日志及窗口实际材质。验证完成后终止本次启动的进程和 CUA 工具，保留其他会话进程。
