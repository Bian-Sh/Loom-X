# 设置页原型设计

## 目标

为 OllamaHub 控制中心补充一个与现有原型视觉一致、可从主导航进入的设置页，用于验证设置项的信息架构和基础交互，不接入 WPF 配置持久化。

## 页面结构

- 主导航在“运维”分组中新增“设置”，位于“控制台”之后。
- 设置页沿用现有深色 token、240px 主侧栏、104px 页面标题区、面板、toast 与响应式断点。
- 页面内部使用二级分组导航和单一内容面板，包含“通用、连接、更新、数据与隐私、关于”五组。

## 设置项

- 通用：界面语言、主题、启动时打开控制中心。
- 连接：直连、系统代理、自定义代理、可选认证信息和连接测试。
- 更新：当前版本、自动检查、稳定版或预览版渠道、手动检查。
- 数据与隐私：匿名诊断数据、日志保留周期、数据目录、清除日志。
- 关于：版本和平台、项目主页、问题反馈、导出脱敏诊断摘要。

## 交互与边界

- 分组切换、开关、选择框、代理测试、更新检查和诊断操作均提供原型级反馈。
- 原型不读取、修改或保存真实应用配置；涉及文件与联网的操作只显示模拟结果。
- 小屏下隐藏主侧栏，二级分组改为横向滚动，设置行纵向排列。

## 验收标准

- 六个原型页面之间可通过主导航互相到达，当前页高亮正确。
- 设置页包含一个 `h1`，分组控件具备可访问名称和状态属性。
- 桌面与移动断点布局不溢出，设置页脚本通过语法检查。
- `.design/scripts/validate.ps1` 通过，清单中存在六个 active 页面且内部链接有效。
