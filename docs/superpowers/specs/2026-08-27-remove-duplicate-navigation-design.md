# 删除重复页面跳转设计

## 目标

简化 `.design` 五页原型的入口层级，删除内容区中与左侧主导航重复的页面跳转，避免同一目标出现多个入口。

## 范围

- 概览页：删除“复制本地 endpoint”“打开活动记录”“管理 Provider”“查看全部”。
- 活动页：删除“查看概览”、两处“查看模型”和“查看 Provider”。
- Provider 页：删除“查看路由”。
- 活动页：删除“刷新活动”，改为每 30 秒静默自动刷新当前活动筛选结果。
- 保留品牌返回概览、左侧主导航，以及复制、刷新、筛选等当前页面操作。

## 实现约束

- 仅修改 `.design/pages/*/index.html` 中对应的 HTML 结构。
- 不改变页面功能脚本、样式、导航路径或其它文案。
- 完成后运行 `.design/scripts/validate.ps1`。
