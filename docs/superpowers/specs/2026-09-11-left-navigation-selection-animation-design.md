# 左侧导航选中态与滑动动画设计

## 背景

左侧主导航目前使用 `ToggleButton` 的内部 `IsChecked` 状态显示当前页面。控件点击时会先改变自身状态，而 ViewModel 的导航状态通过单向绑定维护，导致当前页面仍在显示时，导航项可能短暂或持续显示为未选中。选中背景也按每个按钮独立渲染，页面切换时不会形成连续的移动效果。

## 目标

- 当前页面对应的导航项始终保持选中态，点击当前项不会取消选中。
- 导航选中框只有一个，页面切换时从旧导航项平滑移动到新导航项。
- 动画使用约 180ms 的 ease-out 过渡，不改变现有页面导航、标题和 ViewModel 生命周期。
- 保留现有导航顺序、图标、文案、尺寸和颜色资源。

## 设计

### 状态与交互

`NavigationItemViewModel.IsActive` 是唯一的导航选中状态来源。导航项使用普通 `Button` 执行既有 `NavigateCommand`，不再让控件内部维护可被点击反转的 toggle 状态。`ShowView` 继续在页面切换时调用 `SetActive`，因此当前页始终有且只有一个 active 项；重复点击当前项只会重新显示同一页面并保持 active。

### 选中框与动画

导航列表增加一个共享的选中框元素，选中框的位置由当前 active 项的索引映射得到。选中框置于导航按钮下方，按钮内容仍负责命中和显示。选中索引变化时，选中框的纵向位置通过 Avalonia `DoubleTransition` 过渡，使用 ease-out 缓动，初次加载直接定位到概览项，避免启动时从错误位置滑入。

导航区域保持固定的单列按钮步长，以便选中框与每个卡片对齐；现有滚动容器继续负责窄窗口和较小高度下的垂直滚动。

### 测试与验证

- 更新 MainWindow XAML 契约测试，确认导航项使用普通按钮、共享选中框和位置过渡。
- 增加导航 ViewModel 行为测试，确认重复执行当前项导航命令后 `IsActive` 仍为 `true`，并确认切换页面时旧项取消、新项选中。
- 运行相关 `dotnet test`，再运行 `dotnet build LoomX.slnx`。

## 非目标

- 不改变页面内容、路由、导航顺序或页面 ViewModel 的复用策略。
- 不新增可配置动画参数，不改动全局主题色和透明度逻辑。
- 不处理其他页面内 ToggleSwitch 或 ToggleButton 的启停交互。
