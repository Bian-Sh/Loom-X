# 设置页外观滑动条设计

## 目标

将设置页“透明程度”和“磨砂程度”的 `NumericUpDown` 改为横向 `Slider`，让连续视觉参数更符合直接操作习惯，同时保留明确的当前数值。

## 范围

- “透明程度”范围调整为 `0–100`，整数步进为 `1`，读数显示百分号；`0` 为最透明档位，但保留轻微背景基底，避免窗口内容因 `alpha=0` 消失。
- “磨砂程度”范围保持 `0–64`，整数步进为 `1`，读数显示整数。
- 每一行右侧使用固定宽度滑动区域，滑块与数值读数并排，避免拖动时布局变化。
- `TransparencyEnabled` 关闭时，两个滑动条与读数继续保持禁用状态。
- 复用现有 `TransparencyOpacity`、`BlurAmount` 双向绑定、外观实时预览和延迟自动保存逻辑。

## 非目标

- 不修改数据库字段或默认值；透明程度有效范围统一放宽为 `0–100`。
- 不增加手动数值输入、重置按钮或新的 ViewModel 状态。
- 不调整代理端口等仍适合精确输入的 `NumericUpDown`。

## 验证

- 视图契约测试确认两个外观参数使用 `Slider`，并保持范围、整数步进和数值绑定。
- 完整测试确认 XAML 编译及现有设置持久化行为不回归。
- 发布桌面包后使用 OllamaHub 窗口专属截图检查对齐、读数和禁用状态。
