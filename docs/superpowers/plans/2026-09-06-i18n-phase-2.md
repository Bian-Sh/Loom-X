# i18n Phase 2 实现计划

**目标：** 完成 Providers/Gateway/Placeholder 视图与 ViewModel 的中文硬编码迁移，新增 en-US 卫星程序集，配套 CJK 扫描与键一致性测试，桌面端可切 en-US 显示全英文。

**架构：** 完全复用 Phase 1 建立的 `LocaleService` + `ResourceManager` + `{l:Locale}` + `IStringLocalizer<T>` 组合，不改动基线机制；ViewModel 用 `Status = Loc(key)` 模式；AXAML 用「数字绑定 + 静态翻译文本」分离显示代替 `StringFormat` 嵌套。

**技术栈：** Avalonia 11.3.20、.NET 10、ResX 卫星程序集、xUnit。

## 任务 6：迁移 GatewayViewModel.cs

**目标：** 接入 `IStringLocalizer<T>`，替换所有 UI 文案硬编码。

**步骤 1：添加 Localizer 字段与构造参数**

```csharp
using System.Globalization;
using Microsoft.Extensions.Localization;
using LoomX.Localization;

public sealed class GatewayViewModel : NotifyViewModel, IDisposable
{
    private readonly IStringLocalizer<GatewayViewModel> _loc;
    
    public GatewayViewModel(AppDataStore dataStore, ..., IStringLocalizer<GatewayViewModel>? localizer = null)
    {
        _loc = localizer ?? LocalizerFactory.Create<GatewayViewModel>();
        LocaleService.CultureChanged += OnCultureChanged;
        // 保留原有构造逻辑
    }
    
    private string Loc(string key) => _loc[key]?.Value ?? key;
    private string LocFormat(string key, params object[] args) =>
        args.Length == 0 ? Loc(key) : string.Format(CultureInfo.CurrentCulture, Loc(key), args);
}
```

## 任务 10：新增 LocalizationNoCjkTest.cs

**目标：** 静态扫描禁止中文残留。

**文件：** `LoomX.Tests/LocalizationNoCjkTest.cs`

**步骤 1：编写测试**

```csharp
using System.Text.RegularExpressions;
using System.Xml.Linq;
using Xunit;

namespace LoomX.Tests;

public class LocalizationNoCjkTest
{
    private static readonly Regex CjkPattern = new("[一-龥]", RegexOptions.Compiled);
    private static readonly Regex LogLinePattern = new(
        @"logger\.|Log[A-Z][a-z]+[a-z]*\(",
        RegexOptions.Compiled | RegexOptions.IgnoreCase);

    private static string SolutionRoot =>
        Path.GetFullPath(Path.Combine(typeof(LocalizationNoCjkTest).Assembly.Location, "..", "..", "..", ".."));

    [Fact]
    public void AxamlFiles_DoNotContainHardcodedChinese()
    {
        var viewsDir = Path.Combine(SolutionRoot, "LoomX", "Views");
        var offenders = new List<string>();
        foreach (var file in Directory.EnumerateFiles(viewsDir, "*.axaml", SearchOption.AllDirectories))
        {
            var lines = File.ReadAllLines(file);
            for (var i = 0; i < lines.Length; i++)
            {
                if (CjkPattern.IsMatch(lines[i]))
                    offenders.Add($"{Path.GetRelativePath(SolutionRoot, file)}:{i + 1}:{lines[i].Trim()}");
            }
        }
        Assert.True(offenders.Count == 0,
            $"AXAML files contain hardcoded Chinese:\n{string.Join("\n", offenders)}");
    }

    [Fact]
    public void ViewModels_DoNotContainHardcodedChinese_ExceptLogsAndComments()
    {
        var vmDir = Path.Combine(SolutionRoot, "LoomX", "ViewModels");
        var offenders = new List<string>();
        foreach (var file in Directory.EnumerateFiles(vmDir, "*.cs", SearchOption.AllDirectories))
        {
            var lines = File.ReadAllLines(file);
            for (var i = 0; i < lines.Length; i++)
            {
                var line = lines[i];
                // 跳过注释行
                var trimmed = line.TrimStart();
                if (trimmed.StartsWith("//") || trimmed.StartsWith("*") || trimmed.StartsWith("/*"))
                    continue;
                // 跳过日志调用行
                if (LogLinePattern.IsMatch(line))
                    continue;
                if (CjkPattern.IsMatch(line))
                    offenders.Add($"{Path.GetRelativePath(SolutionRoot, file)}:{i + 1}:{line.Trim()}");
            }
        }
        Assert.True(offenders.Count == 0,
            $"ViewModel files contain hardcoded Chinese (excluding logs/comments):\n{string.Join("\n", offenders)}");
    }

    [Fact]
    public void ResourcesDirectory_IsExcludedFromScan()
    {
        // 文档性测试：说明 Resources/ 下的 .resx 是本地化源文件，允许中文
        var resourcesDir = Path.Combine(SolutionRoot, "LoomX", "Resources");
        Assert.True(Directory.Exists(resourcesDir));
        Assert.True(File.Exists(Path.Combine(resourcesDir, "Strings.resx")));
    }
}
```

## 任务 11：新增 LocalizationResourceParityTest.cs

**目标：** 断言 en-US 键数 ≥ zh-CN 键数。

**文件：** `LoomX.Tests/LocalizationResourceParityTest.cs`

**步骤 1：编写测试**

```csharp
using System.Resources;
using Xunit;

namespace LoomX.Tests;

public class LocalizationResourceParityTest
{
    private static string ResourceDir =>
        Path.GetFullPath(Path.Combine(typeof(LocalizationResourceParityTest).Assembly.Location, "..", "..", "..", "..", "LoomX", "Resources"));

    private static Dictionary<string, string> LoadResx(string culture)
    {
        var file = culture is null or ""
            ? Path.Combine(ResourceDir, "Strings.resx")
            : Path.Combine(ResourceDir, $"Strings.{culture}.resx");

        Assert.True(File.Exists(file), $"Missing resource file: {file}");

        var result = new Dictionary<string, string>();
        using var reader = new ResourceReader(file);
        foreach (DictionaryEntry entry in reader)
        {
            if (entry.Key is string key && entry.Value is string value)
                result[key] = value;
        }
        return result;
    }

    [Fact]
    public void EnUs_ContainsAllZhCnKeys()
    {
        var zhCn = LoadResx(null);
        var enUs = LoadResx("en-US");

        var missing = zhCn.Keys.Where(k => !enUs.ContainsKey(k)).ToList();
        Assert.True(missing.Count == 0,
            $"en-US missing keys:\n{string.Join("\n", missing)}");
    }

    [Fact]
    public void EnUs_HasNoEmptyValues()
    {
        var enUs = LoadResx("en-US");
        var empty = enUs.Where(kvp => string.IsNullOrWhiteSpace(kvp.Value)).ToList();
        Assert.True(empty.Count == 0,
            $"en-US has empty values:\n{string.Join("\n", empty.Select(kvp => kvp.Key))}");
    }

    [Fact]
    public void EnUs_DoesNotHaveOrphanKeys()
    {
        var zhCn = LoadResx(null);
        var enUs = LoadResx("en-US");

        var orphans = enUs.Keys.Where(k => !zhCn.ContainsKey(k)).ToList();
        Assert.True(orphans.Count == 0,
            $"en-US has orphan keys not in zh-CN:\n{string.Join("\n", orphans)}");
    }
}
```

**步骤 2：ResourceReader 对 .resx XML 的支持**

`System.Resources.ResourceReader` 直接读 XML `.resx` 是官方支持的方式，不需要额外依赖。

**验证：** `dotnet test --filter LocalizationResourceParityTest` 全绿。
